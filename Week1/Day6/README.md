A histogram shows the distribution of numerical data by grouping values into ranges (bins) and displaying their frequencies.

Key Learning
Histograms help identify patterns and distributions in data.

AWS Learning
Amazon EC2
What is Amazon EC2?
Amazon Elastic Compute Cloud (EC2) is a cloud computing service that provides scalable virtual servers on demand.

Key Learning
EC2 allows organizations to run applications without purchasing physical hardware.

Important Concepts
Instance
A virtual server running in AWS.

Security Group
A virtual firewall that controls incoming and outgoing network traffic.

Instance Types
Configurations that define:

CPU
Memory
Storage
Network Capacity
Examples:

t2.micro
t3.micro
m5.large
EC2 Use Cases
Web Hosting
Run websites and web applications.

Backend APIs
Host REST APIs and microservices.

Machine Learning
Deploy trained ML models for inference.

Database Hosting
Run database servers and applications.

EC2 vs S3
EC2	S3
Compute Service	Storage Service
Runs Applications	Stores Files
Virtual Server	Object Storage
Processes Data	Stores Data

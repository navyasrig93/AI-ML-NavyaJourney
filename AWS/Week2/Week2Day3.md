Day 3 - AWS Billing & Pricing
AWS Pricing Model
AWS follows a:

Pay-As-You-Go
pricing model.

Customers pay only for the resources they actually use.

Benefits
No upfront investment
Flexible resource usage
Better cost control
Scalable pricing
On-Demand Pricing
What is On-Demand?
Pay only when resources are running.

Example
Run an EC2 instance for 2 hours
Pay only for 2 hours
Benefits
No long-term commitment
Suitable for testing and development
Flexible and predictable
Reserved Instances
What are Reserved Instances?
Resources reserved for:

1 Year
or
3 Years
in exchange for lower pricing.

Benefits
Lower cost than On-Demand
Predictable expenses
Suitable for long-term workloads
AWS Free Tier
AWS provides limited free usage for learning and experimentation.

Examples
Amazon EC2
Amazon S3
AWS Lambda
Amazon RDS
within service-specific usage limits.

Benefit
Allows beginners to learn AWS with minimal cost.

AWS Cost Management Tools
AWS Billing Dashboard
Provides visibility into:

Current Charges
Service Costs
Resource Usage
AWS Cost Explorer
Used to:

Analyze spending trends
Identify expensive services
Forecast future costs
AWS Budgets
Allows users to create spending limits.

Example
Alert me if my AWS bill exceeds $20.
Why Cost Monitoring Matters
Cost monitoring helps:

Prevent unexpected charges
Stay within budget
Optimize cloud spending
Improve resource utilization
Billing & AI/ML
AI/ML workloads can become expensive due to:

Compute Resources
GPU Usage
Model Training Jobs
Data Storage
Monitoring AWS costs helps organizations optimize AI/ML infrastructure.

Key Learning Points
✅ AWS uses a Pay-As-You-Go pricing model

✅ On-Demand pricing offers flexibility

✅ Reserved Instances reduce long-term costs

✅ Free Tier supports learning and experimentation

✅ AWS Cost Explorer helps analyze spending

✅ AWS Budgets helps control expenses

✅ Cost monitoring is important for AI/ML workloads

Interview Notes
What is Pay-As-You-Go?
You pay only for the AWS resources you consume.

What is an On-Demand Instance?
A resource that is billed based on actual usage without long-term commitment.

What are Reserved Instances?
Discounted AWS resources purchased for a longer commitment period.

Why Monitor Costs?
To prevent overspending and optimize cloud resource utilization.

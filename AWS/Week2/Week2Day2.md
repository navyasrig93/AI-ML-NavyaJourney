Day 2 - Amazon CloudWatch
What is Amazon CloudWatch?
Amazon CloudWatch is a monitoring and observability service that helps monitor AWS resources, applications, and infrastructure.

Why CloudWatch is Important
CloudWatch helps organizations:

Monitor system health
Track resource performance
Detect problems early
Improve reliability
Reduce downtime

Interview Notes
What is a Metric?
A measurement collected from an AWS resource.

What is an Alarm?
An action or notification triggered when a metric crosses a threshold.

What is Monitoring?
Tracking the health and performance of systems and applications.

What is Observability?
Using metrics, logs, and events to understand system behavior.

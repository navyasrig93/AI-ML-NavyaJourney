Day 4 - AWS Security Services
Why Cloud Security Matters
Cloud environments are accessible over the internet and contain sensitive business and customer data.

AWS provides security services to help organizations:

Protect applications
Secure data
Manage encryption
Control access
Reduce security risks
AWS Shield
What is AWS Shield?
AWS Shield is a managed Distributed Denial of Service (DDoS) protection service.

Purpose
Protect AWS applications and resources from attacks intended to overwhelm systems with traffic.

Benefits
Automatic Protection
Improved Availability
Reduced Downtime
Enhanced Security
Example
Protecting a public website from a large-scale traffic attack.

AWS WAF
What is AWS WAF?
AWS WAF (Web Application Firewall) helps protect web applications and APIs from common web exploits.

Protection Against
SQL Injection
Cross-Site Scripting (XSS)
Malicious Requests
Bot Traffic
Benefits
Improved Application Security
Custom Security Rules
Protection from Common Attacks
AWS KMS
What is AWS KMS?
AWS Key Management Service (KMS) is a managed service for creating and managing encryption keys.

Uses
Data Encryption
Key Management
Access Control
Secure Storage
Benefits
Simplified Encryption Management
Centralized Key Control
Regulatory Compliance Support
AWS Secrets Manager
What is AWS Secrets Manager?
AWS Secrets Manager securely stores and manages sensitive information.

Examples of Secrets
Database Passwords
API Keys
Access Tokens
Application Credentials
Benefits
Secure Storage
Automatic Secret Rotation
Centralized Management

Interview Notes
What is AWS Shield?
A managed DDoS protection service.

What is AWS WAF?
A web application firewall that protects applications from common web attacks.

What is AWS KMS?
A managed service for encryption key management.

What is AWS Secrets Manager?
A service for securely storing and managing passwords, API keys, and application secrets.

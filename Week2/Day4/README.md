Statistical Concepts
Mean
Definition
The average value in a dataset.

Formula
Sum of Values / Number of Values
Example
scores = [78,82,85,90,95]

mean = sum(scores)/len(scores)
Result
86
Business Importance
Businesses use averages to identify trends and support decision-making.

Median
Definition
The middle value in a sorted dataset.

Example
78, 82, 85, 90, 95
Result
85
Why Median Matters
Median is useful when data contains extreme values because it is less affected by outliers.

Mode
Definition
The most frequently occurring value.

Example
78, 82, 82, 90, 95
Result
82
Business Importance
Mode helps identify the most common customer behavior, product preference, or score.

Range
Definition
Difference between the maximum and minimum value.

Formula
Range = Maximum - Minimum
Result
17
Interpretation
Shows the spread between the highest and lowest values.

Variance
Definition
Measures how far data points are spread from the average.

Interpretation
High Variance → More spread
Low Variance → More consistency
Standard Deviation
Definition
Measures how much values vary from the mean.

Interpretation
Small Standard Deviation → Data is close to average
Large Standard Deviation → Data is widely spread
